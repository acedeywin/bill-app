## Bill App

This is a simple bill application that allows the user to create a bill, add items to the bill, add a tip, and save the bill to a file. The application uses a struct to represent the bill, and methods to format the bill, update the tip, and add items to the bill. The application also uses a switch statement to prompt the user for options and execute different code based on the user's input.

To run the application:

`go run main.go bill.go`

Then follow the prompts in the terminal. The application will create a bill, allow the user to add items and a tip, and save the bill to a file when the user chooses to save the bill. The application will also allow the user to quit the application at any time by choosing the quit option.
